# m-torun/tap

Retired. The apps that were here, [brightsync](https://github.com/m-torun/brightsync)
and [tab-tidy](https://github.com/m-torun/tab-tidy), are signed ad hoc and not
notarized, and macOS blocks Homebrew-installed copies as possible malware.
Build them from source instead; each repository's README says how.

If you installed one from here:

```sh
brew uninstall --cask brightsync tab-tidy   # removes the apps
brew untap m-torun/tap
```
